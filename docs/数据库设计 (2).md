# 数据库设计



## 表清单

| 表名 | 说明 |
| :-- | :-- |
| `user_account` | 用户账户表 |
| `resume` | 简历表 |
| `education_info` | 简历里的教育背景表 |
| `project_info` | 简历里的项目经历表 |
| `intern_info` | 简历里的实习经历表 |
| `award_info` | 简历里的获奖经历表 |
| `resume_template` | 系统预置 LaTeX 简历模板表 |
| `job` | 岗位解析与匹配分析表 |
| `opt` | 简历优化建议表 |

## 通用字段和约定

| 字段 | 类型 | 说明 |
| :-- | :-- | :-- |
| `created_at` | `datetime` | 创建时间，默认当前时间 |
| `updated_at` | `datetime` | 更新时间，更新时刷新 |
| `deleted_at` | `datetime null` | 软删除时间，可选 |
| `status` | `varchar(20)` | 状态字段，按业务表定义枚举值 |

说明：

- 主键统一使用 `bigint unsigned auto_increment`。
- 外键 ID 统一使用 `bigint unsigned`。
- 较长内容使用 `text`。
- PDF 原文件可以保存在项目文件目录或对象存储中，数据库中保存解析后的标准简历信息。
- PDF 抽取出的原始字符串可以作为解析过程中的临时数据；第一版不单独建 `pdf_file` 表。
- Agent 输出建议先通过 Pydantic 校验，再写入 MySQL。

建议约束：

# resume

简历主表保存简历的基础信息、技能集合和个人介绍。教育背景、项目经历、实习经历、获奖经历分别保存在对应明细表中。

| 字段 | 类型 | 说明 |
| :-- | :-- | :-- |
| `resume_id` | `bigint unsigned` | 简历 ID，主键，自增 |
| `user_id` | `bigint unsigned` | 关联用户 ID |
| `resume_template_id` | `bigint unsigned null` | 关联用户选择的 LaTeX 模板 ID，可为空 |
| `title` | `varchar(100)` | 简历标题 |
| `skill_name` | `text` | 简历里的技能名称集合，如 Spring Boot、MySQL、Redis |
| `personal_context` | `text` | 简历里的个人介绍 |
| `status` | `varchar(20)` | `DRAFT`、`SAVED`、`ARCHIVED` |
| `created_at` | `datetime` | 创建时间 |
| `updated_at` | `datetime` | 更新时间 |
| `deleted_at` | `datetime null` | 软删除时间 |

# resume_template

模板表保存系统预置的 LaTeX 代码模板路径。用户上传的 PDF 简历不是模板；模板是系统用于生成最终 LaTeX 简历代码的排版文件。

| 字段 | 类型 | 说明 |
| :-- | :-- | :-- |
| `resume_template_id` | `bigint unsigned` | 简历模板 ID，主键，自增 |
| `template_name` | `varchar(100)` | 模板名称 |
| `latex` | `varchar(255)` | LaTeX 模板文件路径，相对项目路径 |
| `preview_url` | `varchar(255) null` | 模板预览图地址，可选 |
| `status` | `varchar(20)` | `ACTIVE`、`DISABLED` |
| `created_at` | `datetime` | 创建时间 |
| `updated_at` | `datetime` | 更新时间 |

# job

岗位表保存 Boss 直聘等岗位 URL 的抓取内容，以及岗位分析 Agent 输出的匹配度和置信来源等结果。

| 字段 | 类型 | 说明 |
| :-- | :-- | :-- |
| `job_id` | `bigint unsigned` | 岗位 ID，主键，自增 |
| `resume_id` | `bigint unsigned` | 关联简历 ID |
| `job_url` | `varchar(500)` | 岗位 URL |
| `job_name` | `varchar(150) null` | 岗位名称，可选 |
| `company` | `varchar(150) null` | 公司名称，可选 |
| `content` | `text` | 抓取的岗位正文、岗位要求、匹配度、置信来源等分析内容 |
| `status` | `varchar(20)` | `PENDING`、`PARSED`、`FAILED` |
| `created_at` | `datetime` | 创建时间 |
| `updated_at` | `datetime` | 更新时间 |

# opt

优化建议表保存优化 Agent 对已入库简历的分析结果。优化建议只能基于用户已有简历内容，不允许虚构项目、经历、数据或成果。

| 字段 | 类型 | 说明 |
| :-- | :-- | :-- |
| `opt_id` | `bigint unsigned` | 优化 ID，主键，自增 |
| `resume_id` | `bigint unsigned` | 关联简历 ID |
| `job_id` | `bigint unsigned null` | 关联岗位 ID，可为空 |
| `content` | `text` | 优化内容，如技能差距、项目表达、实习表达、STAR/STAT 检查结果 |
| `score` | `decimal(5,2) null` | 简历评分或岗位匹配度评分，可选 |
| `status` | `varchar(20)` | `NEW`、`SAVED`、`USED` |
| `created_at` | `datetime` | 创建时间 |
| `updated_at` | `datetime` | 更新时间 |

## 主要关系

| 关系 | 说明 |
| :-- | :-- |
| `user_account.id` 1 —— N `resume.user_id` | 一个用户可以有多份简历 |
| `resume.resume_id` 1 —— N `education_info.resume_id` | 一份简历可以有多条教育经历 |
| `resume.resume_id` 1 —— N `project_info.resume_id` | 一份简历可以有多条项目经历 |
| `resume.resume_id` 1 —— N `intern_info.resume_id` | 一份简历可以有多条实习经历 |
| `resume.resume_id` 1 —— N `award_info.resume_id` | 一份简历可以有多条获奖经历 |
| `resume_template.resume_template_id` 1 —— N `resume.resume_template_id` | 一个系统预置模板可以被多份简历使用 |
| `resume.resume_id` 1 —— N `job.resume_id` | 一份简历可以对应多个目标岗位 |
| `resume.resume_id` 1 —— N `opt.resume_id` | 一份简历可以生成多条优化记录 |
| `job.job_id` 1 —— N `opt.job_id` | 一个岗位可以对应多条优化建议 |
