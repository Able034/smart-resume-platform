# ID and DCD Diagrams

本文档提供与精简版系统设计一致的交互图和设计类图。简历内容直接由教育背景、项目经历、实习经历、技能、个人介绍和获奖经历组成，图中只保留当前核心流程需要的对象。

每个用例包含：

- Design Sequence Diagram
- Collaboration Diagram
- Design Class Diagram (DCD)

图像由 `id-dcd-puml` 目录下的 PlantUML 源文件生成，SVG 文件位于 `id-dcd-images` 目录。
