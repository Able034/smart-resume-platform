# 数据库设计

## 表清单

| 表名 | 说明 |
| :-- | :-- |
| `user_account` | 用户账户表 |
| `resume` | 简历表 |
| `education_info` | 简历里的教育背景表 |
| `project_info` | 简历里的项目经历表 |
| `intern_info` | 简历里的实习经历表 |
| `award_info` | 简历里的获奖经历表 |
| `resume_template` | 简历模板表 |
| `job` | 岗位解析表 |
| `opt` | 简历优化建议表 |

## 通用字段和约定

| 字段 | 类型 | 说明 |
| :-- | :-- | :-- |
| `created_at` | `datetime` | 创建时间，默认当前时间 |
| `updated_at` | `datetime` | 更新时间，更新时刷新 |
| `deleted_at` | `datetime null` | 软删除时间，可选 |
| `status` | `varchar(20)` | 状态字段，按业务表定义枚举值 |

- 

# user_account

| 字段 | 类型 | 说明 |
| :-- | :-- | :-- |
| `id` | `bigint unsigned` | 用户 ID，主键，自增 |
| `account` | `varchar(50)` | 登录账号，唯一，不能为空 |
| `password_hash` | `varchar(255)` | 加密后的密码，不能为空 |
| `email` | `varchar(100)` | 邮箱，唯一 |
| `status` | `varchar(20)` | `ACTIVE`、`DISABLED` |
| `role` | `varchar(20)` | `USER`、`ADMIN` |
| `register_time` | `datetime` | 注册时间 |
| `last_login_time` | `datetime null` | 最近登录时间 |
| `created_at` | `datetime` | 创建时间 |
| `updated_at` | `datetime` | 更新时间 |

建议约束：

- `account` 加唯一索引。
- `email` 加唯一索引。

# resume

| 字段 | 类型 | 说明 |
| :-- | :-- | :-- |
| `resume_id` | `bigint unsigned` | 简历 ID，主键，自增 |
| `user_id` | `bigint unsigned` | 关联用户 ID |
| `resume_template_id` | `bigint unsigned null` | 关联简历模板 ID，可为空 |
| `title` | `varchar(100)` | 简历标题 |
| `skill_name` | `text` | 简历里的技能名称集合，如 Spring Boot、MySQL、Redis |
| `personal_context` | `text` | 简历里的个人介绍 |
| `status` | `varchar(20)` | `DRAFT`、`SAVED`、`ARCHIVED` |
| `created_at` | `datetime` | 创建时间 |
| `updated_at` | `datetime` | 更新时间 |
| `deleted_at` | `datetime null` | 软删除时间 |

# job

| 字段 | 类型 | 说明 |
| :-- | :-- | :-- |
| `job_id` | `bigint unsigned` | 岗位 ID，主键，自增 |
| `resume_id` | `bigint unsigned` | 关联简历 ID |

| `updated_at` | `datetime` | 更新时间 |

# opt

| 字段 | 类型 | 说明 |
| :-- | :-- | :-- |
| `opt_id` | `bigint unsigned` | 优化 ID，主键，自增 |

| `created_at` | `datetime` | 创建时间 |
| `updated_at` | `datetime` | 更新时间 |
